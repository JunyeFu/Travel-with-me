# Travel With Me UI Visual Style Guide

> 当前 2D 视觉规范 | 产品边界见 [产品总纲](../product/architecture-blueprint.md)。

本文档用于锁定当前成熟 UI 风格。后续新增功能时，默认保持此风格，不另起一套视觉语言。

3D 已封存，其历史视觉材料不约束活动 2D 页面。本文档负责颜色、布局、图标、控件和视觉一致性。

## 1. 审查结论

当前外观方向已经成立，可以作为后续迭代的视觉基线：

> 温暖纸面旅行手账 + 克制桌面工具。

它不是营销落地页、不是高饱和地图平台，也不是移动 App 风格。界面应该像一本打开的旅行规划本：左侧整理路线，右侧理解空间，所有控件安静、清晰、可重复使用。

后续功能可以增加复杂度，但不能改变以下感受：

- 纸面感：米白、浅灰褐、细线、轻阴影。
- 工具感：左侧列表密度较高，右侧地图留出空间。
- 手账感：活页标签、时间线、小圆点、轻量路线卡。
- 旅行感：陶土红为主强调色，鼠尾草绿和暖金只做辅助。
- 克制感：不使用大面积渐变、强荧光色、厚重阴影和夸张动效。

## 2. 色彩基线

必须优先使用 `css/tokens.css` 中的 CSS 变量。

| 用途     | 变量/颜色                                      | 使用规则                      |
| -------- | ---------------------------------------------- | ----------------------------- |
| 页面底色 | `--bg: #f6f2eb`                                | 全局底，不改成纯白或深色      |
| 主纸面   | `--surface: #fffdf8`                           | sidebar、header、modal 主背景 |
| 强纸面   | `--surface-strong: #ffffff`                    | 卡片、输入框、浮层            |
| 分割线   | `--line: #e8e1d8` / `--line-strong: #d8cec3`   | 细线为主，不用重边框          |
| 正文     | `--text: #24201c`                              | 标题、主要文本                |
| 次级文字 | `--muted: #776f66` / `--muted-2: #9b9288`      | 说明、地址、弱按钮            |
| 主强调   | `--accent: #c95f4a` / `--accent-dark: #a94938` | 主按钮、激活态、危险 hover    |
| 浅强调   | `--accent-soft: #fbede7`                       | 激活卡片、轻提示              |
| 辅助绿   | `#6f8e70` / `#e1ecdd`                          | AI 导入、成功、自然/轻智能感  |
| 工业黄   | `#e6ad00` / `#f2b705`                          | 告警提示；不再作为固定路线色  |

禁止：

- 新增大面积蓝紫、霓虹绿、纯黑深色主题。
- 把主按钮改成高饱和红、亮蓝或渐变。
- 为单个新功能创建一套独立主色。
- 在页面大区块使用装饰性渐变、光球、玻璃拟态背景。

## 3. 布局与位置

桌面端主布局保持：

```text
---------------- workspace tabs ----------------+
| sidebar 35%                  | map 65%         |
| trip title / day tabs        |                 |
| itinerary timeline           | spatial view    |
| cards / routes / actions     | status / tools  |
```

规则：

- 顶部保留活页标签，不用普通导航栏替换。
- 左侧 sidebar 是主要编辑区，右侧 map 是空间理解区。
- 新增高频功能优先放在左侧上下文附近，不要悬浮到地图中央。
- 地图工具放右上或右下，状态提示放地图左下，避免遮挡路线主体。
- 普通表单 Modal 居中，宽度优先 `460-760px`；分享和 JSON 导入使用已确认的地图区域工作台，移动端按可用视口布局。
- 桌面验收视口以 `1280x800`、`1440x900`、`1920x1080` 为主。
- 375px 小屏只做基础回归，不作为当前功能设计主场。

## 4. 形状、圆角和阴影

当前 UI 的圆角是小而克制的。

| 元素              | 推荐形状        |
| ----------------- | --------------- |
| 普通卡片          | `8px`           |
| 输入框/状态条     | `10px`          |
| modal/菜单/路线卡 | `12px`          |
| workspace 活页    | `14px 14px 0 0` |
| 小图标容器/chip   | `999px`         |

阴影规则：

- 默认不用阴影，靠纸面、线条和留白分层。
- hover 卡片只允许轻阴影，例如 `0 6px 18px rgba(38, 31, 24, 0.06)`。
- 浮层/modal 可以更明显，但保持暖黑透明阴影。
- 不使用厚重投影、彩色发光、大面积模糊背景。

## 5. 字体与文字层级

字体栈保持：

```css
'Noto Sans SC', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif
```

常用层级：

- 页面标题：`21px / 800`
- 分组标题：`15px / 800`
- 事件标题：`14px / 800`
- 普通控件：`13px / 700-850`
- 辅助信息：`12px / 400-800`
- chip 和弱标签：`11px / 800`

规则：

- 不用超大 hero 字体。
- 不用负 letter-spacing。
- 按钮文案保持短，能用图标时优先图标。
- 长标题必须省略或换行，不能撑破卡片。

## 6. 图标体系

图标采用 Lucide 风格线性 SVG：

- `viewBox="0 0 24 24"`
- `fill="none"`
- `stroke="currentColor"`
- `stroke-width="1.9"`
- `stroke-linecap="round"`
- `stroke-linejoin="round"`

事件图标显示规则：

- 行程卡图标容器：`24px` 圆形浅底。
- SVG 尺寸：`15px` 左右。
- 颜色跟随 `currentColor`，不要每个图标单独上色。
- 图标表达类别，不表达复杂插画。
- 新图标必须延续同一线宽、圆角端点和 24x24 网格。

禁止：

- 使用彩色 emoji 作为正式图标体系。
- 引入实心图标、3D 图标、复杂插画图标。
- 同一个操作同时出现多种图标风格。

## 7. 组件风格

### Workspace Tabs

- 保持活页本外观。
- 活跃 tab 可用陶土红浅底。
- 第二、第三路线可用暖金、鼠尾草绿。
- 新增入口 `+` 和 `AI 导入` 保持短按钮，不做大 CTA。

### Buttons

- 主操作：陶土红实底，白字。
- 次操作：白底/透明底 + 细线。
- 危险操作：只在 hover 或确认场景使用陶土深红。
- 图标按钮保持 `24-30px`，不要放大成厚重方块。

### Cards

- 行程卡保持轻纸片：白底、8px 圆角、默认无阴影。
- 激活态使用 `--accent-soft`，边线用浅陶土红。
- 操作按钮默认隐藏或弱显示，hover/focus 再显性。
- 时间线左侧圆点和细线不能删除，它们是当前识别度的一部分。

### Modals

- 背景遮罩保持深蓝灰透明 `rgba(15, 23, 42, 0.45)`。
- Modal 背景使用纸面色，不做玻璃态。
- 表单控件使用 `10-12px` 圆角和 `--line` 边框。
- focus ring 使用 `--accent-ring`。

### Map

- 地图区是空间画布，不要堆叠过多卡片。
- 路线使用 `#86B8DB`、`#9CBDC9`、`#B2C6B8`、`#C7CCA6`、`#DDD394` 五档蓝黄离散色号；无时段使用中性灰。凌晨和夜晚同属蓝色，正午偏黄，仅为日照示意。
- 保留原生 Polyline 的白色方向箭头、白描边、粗细、透明度和高亮；不叠加自绘箭头或宝石分面。控制按钮保持纸面风格。

## 8. 动效规则

动效只服务状态反馈：

- hover/active 过渡：`0.15-0.2s ease`。
- modal fade：约 `0.15s`。
- tab 和卡片 hover 可轻微位移或阴影变化。
- 地图选择与路线高亮必须尊重 `prefers-reduced-motion`。

禁止：

- 大范围弹跳、旋转、持续闪烁。
- 为普通按钮添加夸张动效。
- 自动播放影响编辑效率的动画。

## 9. 后续新增 UI 检查清单

新增任何 UI 前先检查：

- 是否复用了现有 CSS 变量？
- 是否仍是米白纸面 + 陶土红强调，而不是新品牌色？
- 圆角是否在 `8/10/12/14/999px` 体系内？
- 图标是否是 24x24 线性、圆端点、`currentColor`？
- 位置是否符合“左编辑、右空间、顶部活页、地图角落工具”？
- 是否避免了卡片套卡片？
- 是否没有 hero 化、营销化、插画化？
- 桌面端 `1440x900` 是否信息密度合适？
- 375px 是否至少不出现致命遮挡？
- `npm run check` 和 Playwright smoke 是否仍通过？

## 10. 当前发现的注意点

- `css/components.css` 中仍有少量历史硬编码颜色，例如 `#ef4444`、`#1f2937`、`#6b7280`。后续改相关组件时应逐步迁移到 tokens，不需要为本次视觉基线立即重构。
- `mobile-view-switch` 是兼容守门控件，不应继续扩展为完整移动端产品语言。
- 当前页面不出现 3D 控件；路线色以 `js/route-guidance.js` 的离散映射为准。
- 分享图可以更精美，但应沿用纸面、细线、陶土红和旅行手账气质，不做社交海报式强营销视觉。
